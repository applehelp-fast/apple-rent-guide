# Инструкция App Store

Статический сайт для покупателей с 12 скриншотами. В исходниках нет логинов, паролей, ключей или внешней аналитики. Откройте `index.html` для просмотра.

## Структура

- Скриншоты 1–5: выход из раздела «Контент и покупки» без выхода из iCloud.
- Скриншоты 6–10: вход в арендованный аккаунт через App Store. После шага 10 объясняется команда `!код` в чате оплаченного заказа без упоминания конкретной площадки.
- Скриншоты 11–12: переход в историю покупок и поиск приложения.

Изображения находятся в `assets/step-1.jpg` … `assets/step-12.jpg`. Перед публикацией проверьте, что на них нет личных данных, которые не должны быть видны покупателям. Если меняется порядок, обновите также подписи в `index.html`.

При открытии сайта страница начинается сверху, даже если в скопированной ссылке остался фрагмент `#login` или другой якорь. Кнопки перехода по этапам прокручивают страницу без изменения ссылки.

## GitHub Pages

1. Создайте репозиторий и загрузите в его корень содержимое этой папки.
2. В репозитории откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
4. Проверьте адрес, который покажет GitHub Pages. Все ссылки на изображения относительные, поэтому сайт работает и в репозитории проекта вида `username.github.io/repository/`.
